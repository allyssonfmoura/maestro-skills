# maestro-skills

Skills do Claude para o **Maestro OS**.

| Skill | O que faz |
|---|---|
| [`maestro-interface`](maestro-interface/) | Sistema de interface (Liquid Glass estilo Apple): computador + versão própria para celular, kit de componentes, regras de botões e alinhamento, régua automática e conferência responsiva. |

## Instalar no Claude Code
```sh
git clone https://github.com/allyssonfmoura/maestro-skills.git
cp -R maestro-skills/maestro-interface ~/.claude/skills/
```
Os dados dos protótipos são fictícios.
